Common MYOB AccountRight import problems it can help detect.

Sales – Items imports can fail because of small file-format differences. The checker looks for several common issues before you try the import.

  • Invalid or malformed numeric values in selected Sales – Items fields
  • Currency-style formatting that can cause amount fields to be rejected
  • Unexpected quotation or delimiter problems in CSV/TXT files
  • Missing or redundant blank transaction separators
  • Field values that exceed selected MYOB Sales – Items length limits
  • Differences from an optional AccountRight export template

FAQ

Does it upload my accounting files?

No. The application runs locally on your Windows PC. No cloud upload or external API is required.

Will it change my original file?

No. When a supported safe fix is available, the application creates a separate corrected copy instead of overwriting the source file.

Which import type does version 0.9.1 beta focus on?

The current product includes explicit checks for MYOB AccountRight Sales – Items imports, plus generic structural checking.

Can it verify customers, items or tax codes inside MYOB?

No. It operates offline and does not connect to your MYOB company file.

Can it help with MYOB Error -25: Invalid amount?

It can detect some file problems that may contribute to an Invalid amount error, such as malformed numeric values or certain formatting issues. Error -25 can have more than one cause, so the application does not guarantee that it will identify or fix every Error -25 case.

What are the system requirements?

Windows 10 or Windows 11, 64-bit.
