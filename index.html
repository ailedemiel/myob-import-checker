MYOB AccountRight Import Checker

Check Sales – Items import files for common formatting and structural problems before importing them into MYOB AccountRight.

Local Windows utility.
Your accounting files stay on your computer. No upload, account, cloud service, or external API is required.

What it checks

  • Common Sales – Items field-format problems
  • Import-file structure and transaction separators
  • Selected numeric and field-length constraints
  • Optional comparison with a template exported from MYOB AccountRight

Safe fixes

When a mechanical issue can be corrected safely, the application can create a corrected copy. Your original file is never overwritten.

System requirements

Windows 10 or Windows 11, 64-bit.

Current release

Version 0.9 beta.

Important limitations

The application checks common import-file problems. It does not guarantee that MYOB AccountRight will accept a file and does not validate accounting correctness.

Because it operates offline, it cannot verify whether customers, items, jobs, tax/GST codes, or other records exist in your MYOB company file.
